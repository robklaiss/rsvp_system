# SMS Message Templates

This file contains the message templates used in the RSVP system. The system will replace the placeholders with actual values when sending messages.

## Guest Status Messages

### Guest Not Approved
```
Hola [Nombre], gracias por confirmar. Por espacio limitado, no podremos incluirte esta vez. Apreciamos tu cariño y comprensión. 💕 [Arami & Alberto]
```

### Guest Approved
```
¡Hola [Nombre]! 🎉 Nos alegra confirmarte para nuestra boda. Encuentra todos los detalles aquí: www.boda.com.py/arami-alberto/asistir Código: [XXXX] 💕
```

## Placeholders
- `[Nombre]`: Guest's first name
- `[XXXX]`: Access code
- `[Arami & Alberto]`: Couple's names (configurable in app settings)
